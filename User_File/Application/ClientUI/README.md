# 老步兵客户端 UI

适配 VT02/VT12 常规版与 2025 RoboMaster Client。客户端通过裁判系统常规链路的
`0x0301` 绘制叠加图形，不向 UART7 键鼠链路发送 UI。

## 显示

使用 1920×1080 客户端坐标，第 9 层：绿色中心十字（960,540），右侧四行英文状态。
中心十字仅为画面参考，未经弹道或相机偏心标定。

| 显示 | 含义 |
| --- | --- |
| MODE | REMOTE 遥控、KEYBOARD 键鼠、STOP 仲裁未许可、UNKNOWN 底盘快照过期 |
| SPEED | 当前选择的平移档：1 / 9、2 / 18、3 / 30；为老步兵抽象速度，不是 m/s |
| SPIN | POSITIVE/NEGATIVE 旋转请求，FOLLOW 跟随模式，STOP 无旋转请求 |
| FRIC | 两个摩擦轮任一反馈绝对转速大于 1 rad/s 为 ROTATING，否则 STOP；反馈离线/过期为 UNKNOWN |

速度档不是当前轮速；旋转状态不是电机执行确认；ROTATING 不代表达到允许发射转速。
WASD/Shift 对应第一/第二档，遥控按 CH7 三档；Q/E 双键抵消显示 STOP。

## 调度和启用

云台板统一绘图，底盘板仅上报显示数据，不改变控制协议或运行许可。
ControlTask 在机构更新后采集状态；StatusTask 100 Hz 调用非阻塞刷新，未新增任务。
云台每 100 ms 最多提交一包，四行状态和准星轮询，一轮约 500 ms。
DMA 忙/提交失败保留绘制步骤重试，提交成功不等于客户端收到。
首次获得机器人 ID 或裁判链路恢复时只删除本 UI 的第 9 层再创建图形；
每 5 s 重新添加固定名称的图形，以恢复客户端重启或偶发丢失，平时不周期清屏；勿让其他 UI 使用该层。

`User_Config/Board/client_ui_config.h` 的 `BoardConfig_ClientUIUart()` 默认返回 nullptr：
**当前固件不会发送 UI，等待接线确认后绑定云台板的裁判 User 串口。**
仅可绑定独占、已配置 115200 8N1 与 RX/TX DMA 的端口，禁止复用 UART7、SBUS 或 IMU 端口。
端口确认后同步检查 IOC、初始化配置和 BSP 管理对象；底盘板无需裁判串口。
必须先收到最近 500 ms 的合法 `0x0201` 步兵 ID（3–5 或 103–105），才能发送到 `0x100 + robot_id` 对应客户端；
普通裁判帧不延长机器人 ID 时效，不硬编码队伍颜色或机器人编号。

## 双板显示协议

FDCAN2 标准帧 `0x067`，底盘 → 云台，每 50 ms 提交最新状态，8 字节：

| 字节 | 内容 |
| --- | --- |
| 0 | 固定 0x10，版本 1 |
| 1 | 递增 uint8 序号，允许回绕 |
| 2 | 模式：0 停机，1 遥控，2 键鼠 |
| 3 | 速度档：0 未知，1/2/3 |
| 4 | 旋转请求：0 停止，1 正转，2 反转，3 跟随 |
| 5–7 | 保留为零 |

停机帧档位与旋转清零。校验长度、版本、枚举和保留位；200 ms 内序号增量
只接受 1–127，重复/倒退不更新快照。超过 200 ms 无新帧显示 UNKNOWN，后续合法帧重新建立序号基准。
ControlTask 停止采集时底盘上报 STOP。此协议仅显示，不续期键鼠/遥控许可，也不撤销失联停机。
两板更新后完整显示；只更新云台时底盘信息为 UNKNOWN。

## 验收

绑定并连接裁判 User 串口，确认合法本机 ID 和客户端对应机器人身份。
检查中心参考线、CH5 切源、CH7 三档、Shift 第一/第二档、Q/E 正反转及双键抵消、跟随恢复、摩擦轮转动/停止。
断开板间 CAN 后底盘信息应在 200 ms 后显示 UNKNOWN；关闭客户端再打开，5 s 内开始重建。
本次不烧录、不进行实机绘图验收。

主机替身测试已覆盖 CRC、客户端 ID、坐标/文字编码、DMA 忙重试、
200/201 ms 时效边界、序号回绕/重复/倒退、首次未收到状态及周期重建。
主机测试不替代 UART 接线、裁判链路和客户端实机验收。

协议依据：[DJI 2025 串口协议 V1.9.0](https://www.robomaster.com/en-US/resource/pages/announcement/1768)，0x0301 / 0x0100 / 0x0102 / 0x0110。
