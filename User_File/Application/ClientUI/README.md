# 老步兵云台 UI 回传

客户端绘图由配套 Infantry_Chassis 工程的 ClientUI 负责。
云台不发送裁判串口绘图，UART7 继续用于图传键鼠接收。

ControlTask 在 Shoot 更新和诊断发布后采集新鲜且在线的 ShootFeedback：
左右摩擦轮反馈绝对转速 rad/s、摩擦轮转动状态、拨弹盘转动状态。
转动门限均为 1 rad/s，不等于摩擦轮达速或弹丸发射成功。
自瞄状态取 InputState 与现有仲裁结果：关闭、等待目标/许可、仲裁采用视觉目标；
本工程尚未接视觉设备，当前输入适配未开启视觉，因此实际为关闭。
StatusTask 每 50 ms 尝试提交一个 0x068 帧；采集超过 200 ms 后发送全未知。
不修改控制仲裁、设备使能或失联保护。Pitch 复用既有 INS 0x143/0x144 回传。

## 双板显示协议

FDCAN2 标准帧 `0x068`，云台 → 底盘，每 50 ms 提交一次，8 字节。
版本 2：

| 字节 | 内容 |
| --- | --- |
| 0 | 固定 0x20，版本 2 |
| 1 | 递增 uint8 序号，允许回绕 |
| 2 bit 0–1 | 摩擦轮：0 未知，1 停止，2 转动；3 非法 |
| 2 bit 2–3 | 拨弹盘：0 未知，1 停止，2 转动；3 非法 |
| 2 bit 4–5 | 自瞄：0 未知，1 关闭，2 等待，3 仲裁采用视觉目标 |
| 2 bit 6 | 左右转速有效；有效时摩擦轮状态不能为未知 |
| 2 bit 7 / byte 3 | 保留为零 |
| 4–5 | 左摩擦轮绝对转速，小端 uint16，0.1 rad/s |
| 6–7 | 右摩擦轮绝对转速，小端 uint16，0.1 rad/s |

速度无效时 byte 4–7 必须全零；编码拒绝非有限值、负值和大于 6553.5 rad/s 的有效速度。
速度来自新鲜且在线的 ShootFeedback，显示边界再换算为 RPM。
接收端继续校验长度、版本、枚举和保留位；200 ms 内序号增量只接受 1–127，
重复/倒退不更新快照。超过 200 ms 无新帧，摩擦轮指针与自瞄亮条隐藏、LOAD 变白；
后续合法帧重新建立序号基准。云台采集停止超过 200 ms 后发送全未知。
底盘本地采集停止超过 200 ms 时 Pitch 隐藏、圆环变青并取消方向缺口。

新底盘兼容旧 `0x10` 摩擦轮状态帧，其余字段保持未知，不将零转速当作有效反馈。
新云台发送 `0x20`，旧底盘会拒绝，完整 HUD 需两板配套更新；旧版 0x067 不使用。
此协议仅显示，不续期任何控制许可，也不撤销失联停机。

## 显示与验收

配套底盘改为弧形 HUD，七个动态图元合并为一包。
完整布局、颜色与接线见 [底盘 UI 说明](../../../../Infantry_Chassis/User_File/Application/ClientUI/README.md)。

## 显示诊断与报警

保留 `0x068` 版本 2，新增未占用的 FDCAN2 标准帧 `0x069`，每 50 ms 非阻塞提交。byte0=`0x10`，byte1=独立 uint8 序号，byte2–5=Robot_Diagnostic_Topic 小端 uint32 故障位图；byte6 的 bit0/1/2/3 分别为许可、等待、控制快照新鲜（≤50 ms）和快照有效；byte7 的 bit1/2/3/4 分别为来源许可失效、UART 键鼠失效、INS 无效和队列溢出，其余为零。仅按当前所选键鼠来源附加键鼠失效原因，初始化失败锁存。采集停止超过 50 ms 后置控制失效，撤销显示许可和等待，不把旧电机细节作为当前故障。

底盘独立检查 `0x069` 长度/版本/标志及序号：200 ms 内只接受向前差 1–127；重复不续期，255→0 合法，201 ms 起以诊断过期替换旧故障。最多三行 C/G 异常，故障橙色、等待黄色，同因去重，连续健康 500 ms 后清除；超过三项显示前两项及剩余数量。健康键鼠不因遥控缺席报警，暂停不构造故障。不增加发射达速或热量提示。

报警优先于模式文字和静态重建，保留七图元动态包与最小 100 ms 绘图间隔。键位与速度、恢复释放门见 [键鼠控制](../Input/KEYBOARD_CONTROL.md)；完整排序、故障位定义与 HUD 验收见配套底盘 UI 说明。本轮须两板配套更新，未执行烧录。底盘自身 HardFault 或裁判发送链路中断时 HUD 可能冻结，不能替代原控制保护。
