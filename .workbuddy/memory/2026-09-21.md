### 架构事实（与底盘板移植记录互为镜像）

- 老步兵是双板：底盘板（`rm/demo`，已移植到分支 `老步兵测试`）负责底盘电机 / SBUS /
  姿态解算，经 FDCAN2 用 `0x065`（火控开关、波轮、Pitch 通道，三路大端 int16）把遥控
  转发给云台板；**云台板 = H7_RM**，负责云台 Pitch 轴与发射机构。
- 云台板总线分配：FDCAN1 = DM Pitch `0x009/0x019`（MIT）+ DM3519 摩擦轮 `0x07/0x027`、
  `0x08/0x028`（速度模式）；FDCAN2 = QD4310 Yaw（ID 0）+ M2006 拨弹盘（can_id 1）+
  板间链路 `0x065`；FDCAN3 = DM-IMU（`0x66/0x33`，欧拉角寄存器 0x03）。
- 云台板原工程 `Control_Task` **只调度 `Pitch_Loop` + `Shoot_Loop`**，`Gimbal_Init` /
  `Gimbal_Loop` 被注释（该板 BMI088 硬件故障，`Init.cpp` 里 `System_IMU_Configure` /
  `BSP_BMI088.Init` 也是注释状态）。

## DOB 问题核查（用户问「比如 dob 是用的框架吗」）

**结论：没有用框架的 `Class_DOB_First_Order`，Pitch 用的是内联手写估计。**

- 框架 `User_File/Middleware/Algorithm/DOB/alg_dob.*` 在整个 `User_File/` 里
  **零引用**（grep 全仓只剩它自己的 .h/.cpp），是框架预置但尚未接入的模块。
- Pitch 实际用的是 `Pitch.cpp:415-431` 的「带条件冻结的误差积分器」：
  `dis += 0.40 * pos_err * dt`、`clamp ±0.030`、运动时 `dis -= dis*dt/0.20`。
- 两者语义不同：DOB 用 (y, u) 差分反推扰动、不依赖误差符号；手写的是把位置 PID
  的积分项拆出来单独限幅 + 运动门控。位置环 `K_I = 0.0f`，所以那一路积分实际由
  这个「扰动项」承担。

**若要把 `alg_dob` 接进来，先解决三个结构问题（不是改个系数就能等价替换）：**

1. **名义模型阶次**：`Class_DOB_First_Order` 是一阶惯性
   `tau*dy/dt + y = Gain*(u+d)`；Pitch 轴是二阶 `J*d²θ/dt² = u + d`。阶次不匹配时
   `tau` 取大（趋近纯积分）会让 `Kd = alpha/(Gain*beta)` 爆炸（`beta = 1-exp(-Ts/tau)`；
   tau=10 s、Ts=1 ms 时 beta≈1e-4，Kd 可达 1.5e4 量级）。要正确套用得把被控量选成
   **角速度**（DM-IMU 差分已提供 `pitch_imu_velocity_filtered`），u 换算成速度当量。
2. **输入对齐**：DOB 要求 `y[k]` 与上一周期**实际施加**的 `u[k-1]` 对齐，而
   `pitch_output_torque` 末尾还有 clamp 与取负（`SetMIT(..., -torque)`），
   接的时候要传 clamp 之后的实际值，不能传 PID 原始输出。
3. **与 PID 积分项重叠**：接入后要么让 DOB 取代那一段手写估计，要么显式给位置 PID
   配 `K_I`，不要两路积分同时在线。

按用户此前的要求，这类算法模块的接入**要交互完成**，不要单方面改写。
