## 老步兵云台板移植到 H7_BSP（分支 `老步兵云台`，未提交）

把 `~/code/project/rm/H7_RM`（老步兵**云台板**工程，分支 `新达妙驱动`）的应用层移植进
H7_BSP 的 Application / Device 层，**框架文件（Middleware / System / 既有 Device）未改动**。

### 架构事实（与底盘板移植记录互为镜像）

- 老步兵是双板：底盘板（`rm/demo`，已移植到分支 `老步兵测试`）负责底盘电机 / SBUS /
  姿态解算，经 FDCAN2 用 `0x065`（火控开关、波轮、Pitch 通道，三路大端 int16）把遥控
  转发给云台板；**云台板 = H7_RM**，负责云台 Pitch 轴与发射机构。
- 云台板总线分配：FDCAN1 = DM Pitch `0x009/0x019`（MIT）+ DM3519 摩擦轮 `0x07/0x027`、
  `0x08/0x028`（速度模式）；FDCAN2 = QD4310 Yaw（ID 0）+ M2006 拨弹盘（can_id 1）+
  板间链路 `0x065`；FDCAN3 = DM-IMU（`0x66/0x33`，欧拉角寄存器 0x03）。
- 云台板原工程 `Control_Task` **只调度 `Pitch_Loop` + `Shoot_Loop`**，`Gimbal_Init` /
  `Gimbal_Loop` 被注释（该板 BMI088 硬件故障，`Init.cpp` 里 `System_IMU_Configure` /
  `BSP_BMI088.Init` 也是注释状态）。

### 有意做出的偏差（数值不变，只调分层）

- 通道 → 目标的两级低通（tau=25 ms）与线性映射、火控阈值（700）、波轮映射搬到了
  `Communication`（输入适配），Pitch 只接收已滤波映射的目标角。
- 发射的扳机沿 / 长短按判定仍留在 `Shoot` 状态机内部（与云台板一致），不使用
  `ShootEvent` 队列；`ShootCmd.shoot_mode` 表示扳机电容平，`loader_speed_deg_s` 是
  波轮映射后的拨弹盘输出速度（rad/s，与框架既有 Shoot 实现同义）。
- `Class_DMMotor` 在框架里没有 `IsEnabled()`：摩擦轮的"重新使能"改为**反馈离线即重发**，
  重发间隔仍 100 ms；Pitch 的使能状态机改为内部三态（失能 / 等 2 s / 已使能），
  失能请求不再依赖 DM-IMU 数据，链路中断能立刻断使能。
- Yaw 轴默认关闭（`H7_LEGACY_INFANTRY_GIMBAL_YAW=OFF`），与云台板原工程一致；
  打开后沿用框架的双环 + INS，并把原工程"无限重试使能"改为最多 2 s。
- 不使用框架的"两轴 READY 门控"：云台板 Pitch 是主控轴，Yaw 故障不阻断 Pitch。

## 板级上电配置（`System/Init/Init.cpp`，用户确认「这个要改」）

云台板配置新增 `#if LEGACY_INFANTRY_GIMBAL` 的整段上电 profile，默认配置走 `#else`
保持原样（默认构建 Flash 逐字节不变：121236 B）。四处差异及依据：

| 项目 | 云台板配置 | 依据 |
| --- | --- | --- |
| 两路 DC24 | **打开**（原工程 `false, false`） | `bsp_power.h` 参数序为 `(DC24_0, DC24_1, DC5)`；`(false,false,true)` = 两路 24V 全关，与「摩擦轮无反馈、达妙上位机也读不到电机」吻合。云台 Pitch / DM3519 摩擦轮 / M2006 由板载 24V 供电 |
| `BSP_W25Q64JV.Init()` | **跳过**（原工程同样注释） | 其实现第 49 行 `while (Rx_Buffer != 0x001740EF)` 等 JEDEC ID **死循环**，缺片/坏片会把 `System_Init` 卡死。OSPI 外设与回调照常初始化；回调只在有传输时才解引用 `OSPI_Manage_Object`，`TIM_1ms_…` 由 `Busy_Flag` 短路保护，安全 |
| BMI088 / VQF | 由 `H7_LEGACY_INFANTRY_GIMBAL_YAW` 决定：Yaw 关则不初始化、`SPI_Init(&hspi2, nullptr)` | 云台板该板 IMU 硬件故障；不分回调可避免中断进入未初始化对象。`BMI088_Task` 只阻塞在 `osThreadFlagsWait`（标志由未绑定的 SPI 回调置位）→ 永久阻塞、不占 CPU；`Ins_Task` 直接 `osThreadExit`；`EXTI_Flag_Callback` 由 `Init_Finished_Flag` 守卫 |
| ADC | **保留** `ADC_Init(&hadc1, 1)`（原工程注释） | `BSP_Power.Init` 把 `ADC1_Manage_Object` 绑上，跳过会让 `Get_Power_Voltage()` 指向未初始化缓冲；该外设无副作用 |

编译结果：默认 121236 B（不变）、云台板 123364 B、云台板+Yaw 133636 B。

代价与残留风险：`W25Q64JV` 未初始化期间其 OSPI 回调若被异常触发（正常上电不会）会走到
`Auto_Polling_With_Timeout()`——与原工程上电状态相同，实车跑过；后续若要接 Flash 需恢复
`Init()` 并给 JEDEC 等待加超时。
